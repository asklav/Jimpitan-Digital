Konfigurasi Firebase Cloud Sync

Sinkronkan data secara realtime di semua perangkat pengurus

Masukkan JSON Config dari Firebase Console. Jika dikosongkan, aplikasi akan kembali menggunakan Local Storage.

Petunjuk Aturan Firestore Rules:

Jika muncul error permission, di Firebase Console ubah Rules Firestore ke mode baca/tulis:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} { allow read, write: if true; }
  }
}
