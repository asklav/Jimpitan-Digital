Koneksi proyek sudah dipasang oleh pembuat aplikasi. Pengguna tidak perlu mengatur URL atau key pada perangkat ini.

Penting untuk keamanan

Jangan pernah masukkan service_role key ke halaman web. Aplikasi ini memakai Supabase Auth untuk login pengurus. RLS hanya boleh memberi akses ke akun yang terdaftar aktif pada tabel jimpitan_admins. Aktifkan sinkronisasi hanya setelah akses tabel diamankan sesuai kebutuhan.

Tabel yang perlu dibuat di Supabase → SQL Editor

Jalankan file SQL pemisahan akses. Petugas tidak membaca snapshot penuh; data petugas memakai direktori terbatas dan RPC pencatatan setoran.

Status “Online” baru muncul setelah server benar-benar berhasil dihubungi.
